1. vision.md
PatternForge AI — Product Vision
One-Line Vision
A platform that trains software engineers to think like elite problem solvers, not just accumulate solved problems.
The Problem We Are Solving
There are tens of thousands of students in India and globally who have solved 200, 300, even 500 problems on LeetCode and still fail interviews at product-based companies. They fail not because they lack effort, but because they have been practicing the wrong thing. They have been memorizing solutions, not building thinking ability.
The existing ecosystem — LeetCode, GeeksforGeeks, InterviewBit, Codeforces — measures progress by quantity. Problems solved. Contest ratings. Streaks maintained. None of these platforms measure whether the user can independently discover a solution they have never seen before. And that is precisely what every technical interview demands.
PatternForge AI exists to close this gap.
What PatternForge AI Is
PatternForge AI is an AI-powered DSA intelligence platform that trains pattern recognition, observation quality, formula derivation, and optimization reasoning as explicit, measurable skills. It acts as a personalized coach that diagnoses the root cause of a user's problem-solving failures and prescribes targeted remediation — not more problems, but better thinking.
The platform treats problem solving as a cognitive skill with identifiable sub-skills, each of which can be trained independently and measured objectively.
What PatternForge AI Is Not

It is not another problem repository
It is not a competitive programming platform
It is not a tutorial site that teaches algorithms through videos
It is not a platform where solving more problems automatically makes you better

The Core Philosophy
Every platform today follows this loop:
Problem → Code → Submit → Next Problem
PatternForge replaces this with:
Problem → Observation → Pattern Identification → Formula Discovery
→ Optimization Reasoning → Code → Reflection → Pattern Storage
The objective is to train the brain, not fill a submission history.
The Fundamental Insight
The difference between a candidate who cracks Google and one who doesn't is rarely knowledge. Both likely know what Dijkstra's algorithm is. The difference is that the Google candidate, when looking at a new problem they have never seen, can within minutes identify the algorithmic category, make the key observations, derive the approach from first principles, and write a clean optimal solution.
That ability — independent pattern discovery — is the skill PatternForge trains.
Vision Statement
PatternForge AI will become the first platform in the world that measures and improves a user's ability to independently discover optimal solutions — transforming users from "I know the solution after seeing it" to "I can discover the solution myself."
Target Outcome for Users
A user who spends 3 months on PatternForge should be able to:

Look at any medium-difficulty problem and identify the correct algorithmic pattern within 3–5 minutes
Write down 4–5 meaningful observations before touching the keyboard
Derive the optimization transition (brute → better → optimal) with reasoning
Perform consistently under interview time pressure
Walk into any product company interview with genuine confidence, not rehearsed pattern matching

Long-Term Platform Vision
Phase 1 (0–6 months): MVP — Core thinking loop with Pattern Discovery, Observation Training, AI Feedback, Reflection System, and Pattern Library for individual users
Phase 2 (6–18 months): Interview Simulation Arena with company-specific modes, Adaptive Difficulty Engine, AI Mentor with root cause diagnosis, and Mistake Intelligence System
Phase 3 (18–36 months): Institutional version for colleges and coaching institutes, cohort-based learning, placement analytics dashboard for TPOs, and PatternForge Certification recognized by hiring companies
Phase 4 (3+ years): AI-powered mock interviewer with voice, real-time thinking analysis during sessions, and direct integration with company hiring pipelines
Why Now
The Indian tech hiring market in 2025–26 has become simultaneously more competitive and more pattern-aware. Companies like Google, Microsoft, Amazon, and Razorpay have moved away from memorization-friendly questions toward problems that require genuine derivation ability. The existing preparation ecosystem has not caught up. PatternForge is built specifically for this moment.

3. user-stories.md
PatternForge AI — User Stories
Stories are organized by module and follow the format: As a [user], I want to [action], so that [outcome].

Authentication and Onboarding
US-001

As a new user, I want to register with my email and create a profile including my target companies, timeline, and current platform stats, so that the platform can personalize my experience from day one.
US-002

As a new user, I want to take an AI-powered split skill assessment (a quick 6-step conceptual quiz on registration, plus an optional desktop-only coding challenge), so that the platform knows my actual ability level without causing signup friction.
US-003

As a new user, I want to see my six-dimensional skill profile compiled from my conceptual assessment and optional challenge, so that I understand exactly where I stand and what needs work.
US-004

As a returning user, I want to log in and immediately see my daily challenge, current streak, weekly progress, and AI Mentor note from my last session, so that I can resume practice without friction.

Pattern Discovery Mode (Module 4)
US-005

As a user opening a problem, I want the code editor to be locked until I complete the Pattern Discovery phase, so that I am forced to think before coding.
US-006

As a user in Pattern Discovery, I want to select from a list of algorithmic patterns and write a 2–4 sentence justification for my choice, so that I practice the act of reasoning toward a pattern, not just guessing.
US-007

As a user who guessed the wrong pattern, I want the AI to explain specifically which clue in the problem I missed that points to the correct pattern, so that I learn the trigger, not just the answer.
US-008

As a user who guessed the right pattern, I want the AI to validate my reasoning and note if there was a more direct path to that conclusion, so that I refine my thinking even when I get it right.
US-009

As a user who is completely stuck on pattern identification, I want to receive a single targeted clue (not the answer) pointing me to one overlooked constraint, so that I develop the skill of using clues rather than being given solutions.

Observation Training System (Module 5)
US-010

As a user in the observation phase, I want a structured panel with categories (Input Properties, Output Properties, Constraint Implications, Edge Cases) to fill out before coding, so that I develop a systematic pre-coding checklist.
US-011

As a user, I want the AI to score my observations on completeness, relevance, and depth after I submit the problem, so that I get quantitative feedback on the quality of my pre-coding thinking.
US-012

As a user, I want to see which observations were critical to the optimal solution and which ones I missed, so that I learn what to look for on similar problems in the future.
US-013

As a user, I want to see how the constraint size (10^3, 10^5, 10^9) maps to expected time complexity, highlighted during the observation phase, so that I learn to use constraints as algorithmic filters.

Interactive Coding Playground (Module 9)
US-014

As a user, I want to write and run code in Java, Python, C++, or JavaScript with full syntax support, so that I can practice in my preferred interview language.
US-015

As a user after submission, I want to see the estimated time and space complexity of my solution compared against the optimal, so that I immediately know if an optimization opportunity exists.
US-016

As a user, I want to add my own custom test cases alongside the system-generated ones, so that I practice the habit of proactive edge case testing rather than relying entirely on the judge.
US-017

As a user solving array, tree, or graph problems, I want a step-by-step dry run visualizer that shows pointer movement, tree traversal, and queue/stack states, so that I can debug and verify my algorithm visually.
US-018

As a user, I want to see a breakdown of my time spent in observation, pattern discovery, and actual coding for every problem, so that I can identify if I am spending too little time thinking or too much time debugging.

Pattern Library (Module 8)
US-019

As a user who has completed a problem, I want a Pattern Card automatically generated containing the pattern, trigger clues, key observation, formula, optimization insight, and my specific mistakes, so that I build a personal knowledge database without extra effort.
US-020

As a user preparing for an interview, I want to search and filter my Pattern Library by topic, pattern type, and difficulty, so that I can do a targeted review in under an hour.
US-021

As a user, I want the platform to surface Pattern Cards I have not reviewed in 10+ days during my warmup session, so that spaced repetition is built into my daily practice automatically.
US-022

As a user, I want to see which patterns appear most frequently in my target companies' interview history, highlighted in my Pattern Library, so that I know what to prioritize in the final weeks before an interview.

Formula Discovery Trainer (Module 6)
US-023

As a user, I want to be given input-output tables with no question context and be asked to derive the underlying formula or relationship, so that I build derivation ability rather than formula recall.
US-024

As a user, I want exercises specifically around recurrence relation identification so that I develop the ability to spot DP structure in problems before seeing them framed as DP.
US-025

As a user, I want to practice deriving why specific formulas (n(n+1)/2, 2^n, Catalan numbers, combinations) arise from specific problem structures, so that I build mathematical intuition from first principles.

Pattern Recognition Gym (Module 7)
US-026

As a user in the Pattern Recognition Gym, I want to be shown only raw input-output pairs with no problem statement and asked to infer the hidden relationship, so that I build deep intuition independent of linguistic problem framing.
US-027

As a user, I want the Gym to include deceptive cases — inputs that look like one pattern but are actually another — so that I learn not to jump to conclusions based on surface-level cues.
US-028

As a user, I want to earn points based not just on correctness but on the reasoning quality of my deduction, so that I am incentivized to think carefully rather than guess quickly.

Solution Path Analyzer (Module 12)
US-029

As a user after submission, I want to see a side-by-side comparison of my solution's complexity versus the optimal solution's complexity, so that I immediately understand the efficiency gap.
US-030

As a user, I want the analyzer to tell me specifically which observation I missed that would have led me directly to the optimal solution, so that I connect the observation phase to the solution quality.
US-031

As a user, I want to see all valid approaches to a problem ranked by efficiency with a brief explanation of when to prefer each, so that I understand the full solution space rather than just the single best answer.

AI Test Case Generator (Module 11)
US-032

As a user submitting a solution, I want it tested against standard cases, edge cases (empty, single element, max size, all identical), and adversarial cases automatically, so that I cannot pass with a solution that only works on happy-path inputs.
US-033

As a user who imports a problem with no test cases, I want the platform to generate a complete test suite from the problem description, so that imported problems have the same rigor as native platform problems.

Mistake Intelligence System (Module 13)
US-034

As a user, I want every mistake I make categorized by type (Pattern Error, Formula Error, Optimization Error, Implementation Error, Edge Case Error, Observation Error), so that I see the distribution of my failure modes over time.
US-035

As a user, I want to receive a weekly Mistake Report that identifies my top three recurring weaknesses with specific examples from the week's sessions, so that I know exactly what to focus on.
US-036

As a user, I want the AI to identify when the same root cause is producing different surface-level errors across multiple problems, so that I fix the underlying issue rather than treating each mistake as isolated.

Adaptive Difficulty Engine (Module 14)
US-037

As a user, I want the platform to automatically increase difficulty when I consistently solve problems optimally and decrease it when I am struggling, so that I am always working at the productive edge of my ability.
US-038

As a user within two weeks of a scheduled interview, I want the difficulty to stabilize at Hard and Interview Simulation levels with no new concept introduction, so that I build consistency and speed rather than encountering unfamiliar material.
US-039

As a user on a day I have marked as low-availability (under 45 minutes), I want the daily challenge to automatically reduce to two problems prioritizing my highest-leverage weak areas, so that I get maximum value from limited time.

Interview Simulation Arena (Module 15)
US-040

As a user selecting Google Mode, I want two hard problems with a 45-minute combined timer, evaluated on optimization depth and explanation quality, so that I simulate the actual Google interview experience.
US-041

As a user selecting Amazon Mode, I want medium-hard problems with emphasis on edge case coverage, where the AI asks follow-up questions like "What if n is 10^9?" and "How does this scale?", so that I prepare for Amazon's specific interview style.
US-042

As a user after completing a simulation, I want a detailed post-simulation report with scores per problem, pattern identification accuracy, observation completeness, complexity achieved, and an overall verdict with specific improvement areas, so that every mock interview produces actionable feedback.

AI Mentor (Module 16)
US-043

As a user, I want the AI Mentor to diagnose the root cause of my recurring failures rather than simply telling me to practice more of a topic, so that I fix the actual problem rather than just doing more of the same.
US-044

As a user before a mock interview or real interview, I want the AI Mentor to deliver a focused pre-interview briefing covering my current strengths, specific watch-out areas, and a 30-minute targeted drill recommendation, so that I walk in prepared and self-aware.
US-045

As a user who has shown measurable improvement in a skill, I want the AI Mentor to acknowledge it specifically with data (e.g., "Binary Search trigger accuracy improved from 40% to 85% over 3 weeks"), so that I see concrete evidence of growth and stay motivated.

Reflection System (Module 17)
US-046

As a user who has just completed a problem, I want to answer three structured reflection prompts (pattern missed, most important observation, what I will remember tomorrow, with a fallback checkbox review option if I choose to skip text entry due to cognitive fatigue) before the session closes, so that every problem becomes a permanent learning event.
US-047

As a user who writes a shallow reflection, I want the AI to suggest a soft-warning prompting me to go deeper without blocking session completion, so that reflection remains helpful rather than a rigid chore.
US-048

As a user at the end of each session, I want a Session Summary showing problems attempted, pattern identification accuracy, observation quality score, reflection quality, Pattern Cards generated, and an AI Mentor note for tomorrow, so that every session ends with a clear picture of what happened and what comes next.

User Problem Import (Module 10)
US-049

As a user who encountered a problem in an external assessment or interview, I want to paste the problem text or URL into PatternForge and have it converted into a full platform exercise with generated test cases, so that every problem I encounter anywhere feeds back into my learning system.
US-050

As a user, I want to upload a screenshot of a problem from a company's OA portal and have the platform extract and structure it automatically, so that I can practice OA-style problems inside PatternForge's thinking framework.

Skill Assessment (Module 1)
US-051

As a new user completing the assessment, I want to see not just topic-wise scores but dimensional scores (Pattern Recognition, Observation Quality, Formula Discovery, Optimization Ability, Speed, Consistency) so that I understand the nature of my gaps, not just their location.
US-052

As a returning user after 4 weeks, I want to retake a partial assessment on my weak areas to see if my dimensional scores have improved, so that I have objective evidence of progress beyond just problems solved.

Personalized Learning Engine (Module 2)
US-053

As a user, I want my learning roadmap to be automatically updated after each weekly milestone based on my current performance profile, so that the plan always reflects my actual current state and not a snapshot from 3 weeks ago.
US-054

As a user targeting a specific company, I want my roadmap to gradually shift problem types, difficulty, and topics toward what that company historically asks, so that my preparation is aligned with my actual goal.
